# Privacy

SchemaWeave does not include telemetry, analytics, tracking pixels, advertising code, license calls, or a hosted API dependency.

The WordPress plugin generates structured data from information already available in the local WordPress/WooCommerce installation and from values entered by site administrators. It does not send site content, settings, customer data, product data, or diagnostics to the project maintainers.

If a site owner adds third-party URLs to Organization social profiles, images, or other schema fields, those URLs are emitted into the site's JSON-LD as configured; SchemaWeave itself does not request those resources.

Exported settings files are created locally and downloaded by the authenticated administrator. Import data is processed locally by WordPress.
